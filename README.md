# QUTC GitHub Configuration

本仓库用于维护 QUTC GitHub 组织的：

- 组织主页
- 默认 Issue 模板
- 默认 Pull Request 模板
- 贡献指南
- 行为准则
- 安全政策
- 项目治理规范

## 目录

- `profile/README.md`：公开组织主页
- `.github/ISSUE_TEMPLATE/`：默认 Issue 模板
- `.github/PULL_REQUEST_TEMPLATE.md`：默认 PR 模板
- `CONTRIBUTING.md`：贡献指南
- `CODE_OF_CONDUCT.md`：行为准则
- `SECURITY.md`：安全问题报告方式
- `SUPPORT.md`：支持渠道
- `GOVERNANCE.md`：组织治理说明

本仓库不得存放密码、Token、服务器密钥或其他敏感信息。
