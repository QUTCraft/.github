# QUTC

欢迎来到 QUTCraft 的 GitHub 组织。

我们是一个以 Minecraft 为起点，并延伸到软件开发、服务器运维、数字创作、电子技术和项目协作等方向的高校技术社团。

## 我们在做什么

- 建设 QUTC 社团数字化协作平台
- 开发 Minecraft 相关工具、插件与服务
- 组织软件、硬件和数字创作项目
- 沉淀社团技术文档与项目经验
- 探索聊天机器人与 AI 辅助协作

## 主要项目

- `qutc-platform`：社团官网与数字化协作平台
- `qutc-handbook`：团队协作和项目治理手册
- 更多项目正在筹备中

## 技术方向

- Go / Gin
- Vue 3 / TypeScript / Vite
- MySQL / Redis
- Docker / Linux
- Minecraft 生态开发
- 电路、嵌入式与数字创作
